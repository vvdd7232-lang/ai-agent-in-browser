# Готовые файлы

Здесь лежат собранные бинарники. Скачивать так: открой файл на GitHub → кнопка
**Download** (или **Raw**) справа вверху.

| Файл | Что это |
| --- | --- |
| `ai-agent-in-browser.exe` | Windows x64. Мост + панель в одном файле, **Node не нужен**. Двойной клик — браузер откроется сам |
| `ai-agent-extension.zip` | Расширение для Chrome. Ставится один раз: `chrome://extensions` → *Developer mode* → *Load unpacked* → папка `extension` из архива |

## Запуск

1. Скачай `ai-agent-in-browser.exe`
2. Двойной клик
3. Откроется панель — пиши задачу, команды выполняются в настоящем терминале

Остановка: закрыть окно или Ctrl+C.

Windows может показать «Система Windows защитила ваш ПК» — файл без цифровой
подписи (подпись node.exe снимается при сборке, иначе она становится битой).
Тогда: **Подробнее → Выполнить**.

## Пересобрать

```bash
npm i -D esbuild postject
npm run build:exe          # -> dist/ai-agent-in-browser.exe
```

Подробности — в основном README, раздел «Сборка в один файл (.exe)».

> Файлы лежат в git, потому что это единственный способ отдать их отсюда:
> загрузка ассетов в релизы GitHub (`uploads.github.com`) из среды сборки
> недоступна. Обычная практика — держать такое в релизах, а не в истории.
